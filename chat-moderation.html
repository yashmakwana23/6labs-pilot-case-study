LENS 1

Real-money-trading (RMT) bots run the same ad on four servers — and the filter does nothing

A templated ad — high-tier gear or “300,900 Premium Gems” for real money, pointing to an external “Inquiry Website: an external RMT site” — is reposted across World / Region / All chat across four regional servers by low-level, no-guild, 0-fame bot accounts. The automated filter does nothing; players block and report by hand.

Bot handle A posts an RMT ad in All/World chat — “$49.99 = Premium Gem 300,900 (Inquiry Website: [external RMT site])”. A player opens the Report dialog and selects “Inappropriate message.”

The same bot handle in a different session. The reporter types the reason “spamming link to spend money on another site”; the profile — Lv.32, no guild, zero fame — is stamped “Reported,” the RMT ad still legible behind it.

LENS 2

The restricted-text filter blocks “palabok” and “Buccees,” and never says why

Every rejected message returns one generic popup — “There is text that cannot be used.” — with no hint which word or why. It matches substrings, so it blocks harmless text and profanity alike, and gives players nothing to learn from except how to evade it.

False positive. In an innocuous food conversation the player types “palabok is a type of pan…” and the filter rejects it with the generic “There is text that cannot be used.” notice.

A mild-profanity message to a friend — “damn lost connecttion :P” — is blocked in Whisper with the same generic notice. Even 1-to-1 private chat is filtered.

An expected block (crude innuendo in World chat — content described, not reproduced). It returns the same undifferentiated popup as the harmless cases.

Two costs: legitimate chat gets blocked and frustrates players; and because the notice is generic, players just test around it and evade — defeating the filter for the words it should catch.
LENS 3

Players report spam, not abuse — and a spaced-out slur went through

Two findings. First, the report/block tools are used constantly — but mostly against spam: even messages filed under “Inappropriate message” are RMT ads. Second, on actual abuse the filter is the weak point.

Filed as “Inappropriate message” — but the reported content from Bot handle B is again the same RMT advert.

A genuine harassment case — the abuse the filter misses

In this session one player posts racially demeaning messages targeting a nationality in World chat and spaces out letters (e.g. “p i s s”) to slip past the word filter. No system action follows — other players just reply or move on. Offending text is withheld here and described instead.

Three ways the filter failed on screen

GapWhat happened on screen
Slur evaded by spacinga player fragmented a slur with underscores/spaces and it went through
Profanity pushed througha common profanity reached World chat after several blocked tries
Harassment left standingsustained hostile messaging with no visible system action; players block silently, so the studio never hears
The gap: the filter is strict on innocent substrings yet evaded by anyone who spaces out a slur, and it takes no visible action on sustained harassment. The report taxonomy doesn’t separate spam from abuse, and many players just block silently — so the real signal never reaches the studio.
